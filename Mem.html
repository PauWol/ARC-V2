Core Design Principle

Services are independent and replaceable

ARC separates capability from management. A service describes what something does. Pulse decides when and how it runs.

Ownership Model

Registry

Owns:

  • ServiceInstance
  • State
  • PID
  • Process reference
  • Runtime information

Manager

Owns actions:

  • Start
  • Stop
  • Restart
  • Lifecycle transitions

Monitor

Owns observation:

  • Health checks
  • Failure detection
  • Recovery requests

Important Decision

Service ≠ Process

A service is a capability. A process is one execution instance.
